# Project-06

# Features added
- Multiple models with idle animations
- Interactable quest-giving NPC with conditional quest completion dialogue
	- Objective completion triggers new dialogue using hidden score variable (an integer counting zombie kills)
- Zombie enemies:
	- Simple player tracking
	- Three different animations (idle, walking, and death)
- Hand-held weapon which uses On Trigger Enter and animator parameters to stop zombie movement and trigger death animation
- Simple terrain/obstacles
- Extremely loose implied narrative
